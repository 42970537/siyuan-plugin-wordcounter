## ✨ 功能特性

### 🧠 实时码字追踪
- **实时速率显示**：状态栏实时展示当前打字速度（字/分钟），滑动窗口算法精确计算
- **今日字数统计**：累计当天所有编辑操作产生的净增字数
- **峰值速率记录**：记录今日最高打字速度
- **写作时长统计**：以 8 小时为一天目标的可视化进度条

### 🎭 码字精灵（亮点）
一个纯 SVG 绘制的圆脸小精灵，根据你的码字速率实时切换 **5 种状态**：

| 速率 | 状态 | 表情 | 动画 |
|:---:|:---:|:---:|:---|
| 0 | 💤 闲置 | 闭眼 + Zzz | 缓慢摇摆 |
| <10 字/分 | 🐢 慢速 | O型嘴嘟嘴 | 微微呼吸 |
| 10-30 | 🚶 中速 | 大眼专注 + 微笑 | 微晃 + 笔摆动 |
| 30-60 | 🏃 快速 | 兴奋大笑 | 快速摇摆 + 粒子飞溅 |
| 60+ | 🔥 飞速 | 火焰光芒 | 疯狂抖动 + 多粒子爆发 |

> 💡 **点击精灵可以互动！** 触发弹跳动画 + 随机鼓励语

### 🎨 视觉体验
- **速率主题渐变背景**：Hero 区颜色跟随码字速率实时变化（灰 → 绿 → 蓝 → 橙 → 红）
- **数字跳动动画**：字数变化时触发 scale 弹跳
- **呼吸点指示灯**：状态栏指示灯根据速率切换呼吸频率
- **深色主题适配**：完整支持思源笔记深色模式

### 🖱️ 面板交互
- **自由拖拽**：面板可拖动到屏幕任意位置，不会拖出可视区域
- **点击互动**：点击精灵触发弹跳 + 15 条随机鼓励语
- **浮动详情面板**：点击状态栏弹出完整统计

### 🔧 智能管理
- **闲置自动暂停**：2 分钟无操作自动进入空闲状态
- **数据持久化**：插件数据自动保存，重启不丢失
- **一键重置**：随时可重置今日统计数据

## 📦 安装方法

### 方式一：从集市安装（推荐）
1. 打开思源笔记 → **设置** → **集市** → **已下载**
2. 搜索「**码字统计**」
3. 点击安装并启用

### 方式二：手动安装
1. 下载最新的 [Release](https://github.com/42970537/siyuan-plugin-wordcounter/releases)
2. 解压得到 `siyuan-plugin-wordcounter` 文件夹
3. 将文件夹放入思源工作空间的 `data/plugins/` 目录
4. 刷新思源笔记页面
5. 在 **设置 → 集市 → 已下载** 中启用插件

## 🚀 使用说明

1. **启用后**，右下角状态栏会出现码字统计指示器
2. **开始写作**，速率和字数实时更新
3. **点击状态栏**，查看浮动详情面板（含精灵 + 完整统计）
4. **拖动面板标题栏**，可自由移动面板位置
5. **点击精灵**，获得随机鼓励~

### 字数统计规则
- **中文字符**：每个汉字计 1 字
- **英文单词**：每个连续英文单词计 1 字
- 统计基于编辑器内所有可见文本的**净增量**

### 速率颜色分级
| 等级 | 颜色 | 范围 |
|:---:|:---:|:---:|
| 空闲 | ⚪ 灰色 | 0 |
| 慢速 | 🟢 绿色 | < 10 字/分 |
| 中速 | 🔵 蓝色 | 10-30 字/分 |
| 快速 | 🟠 橙色 | 30-60 字/分 |
| 飞速 | 🔴 红色 | > 60 字/分 |

## 🔧 技术说明

- 通过 `MutationObserver` 监听编辑器 DOM 变化
- 滑动窗口算法计算实时速率（10 秒窗口）
- 数据存储使用思源插件系统的 `saveData/loadData` API
- 精灵角色使用纯 SVG 内联绘制，无外部依赖
- 面板拖拽通过 `mousedown/mousemove/mouseup` 实现

## 📸 预览

> 将鼠标悬停在状态栏指示器上即可看到实时码字速率，点击可展开完整面板。
