## ✨ 功能特性

### 🧠 码字追踪
- **平均速率显示**：基于今日字数÷写作时间的平均输出能力（字/分钟），更稳定可靠
- **今日字数统计**：累计当天所有编辑操作产生的净增字数
- **峰值速率记录**：记录今日最高打字速度
- **目标进度条**：字数目标 + 时长目标，独立开关，可视化进度
- **目标完成动画**：达成目标时进度条弹跳 + 气泡庆祝通知 🎉

### 🎭 码字精灵（亮点）
一个纯 SVG 绘制的圆脸小精灵，根据你的**平均速率**切换 **5 种状态**。支持 **写作模式** 和 **编程模式**，各有专属图标：

| 速率 | 状态 | 写作图标 | 编程图标 |
|:---:|:---:|:---|:---|
| 0 | 💤 闲置 | — | — |
| <10 字/分 | 🐢 慢速 | 小红嘴 | 小蓝嘴 |
| 10-30 | 🚶 中速 | 蓝色笔 ✏️ | 蓝色 `</>` |
| 30-60 | 🏃 快速 | 橙色笔 + 粒子 | 橙色 `</>` + 粒子 |
| 60+ | 🔥 飞速 | 红色笔 + 光芒 + 星星 | 红色 `</>` + 光芒 + 星星 |

> 💡 **点击精灵可以互动！** 触发弹跳动画 + 随机鼓励语

### 🎨 视觉体验
- **速率主题背景**：Hero 区颜色跟随平均速率实时变化（灰 → 绿 → 蓝 → 橙 → 红）
- **数字跳动动画**：字数变化时触发 scale 弹跳
- **爆发弹跳动画**：快速输入时字数放大变金
- **目标完成动画**：进度条弹跳 + 整行绿色闪烁
- **深色/浅色/护眼主题**：完整支持思源笔记多主题

### 🖱️ 面板交互
- **自由拖拽**：面板可拖动到屏幕任意位置，不会拖出可视区域
- **点击互动**：点击精灵触发弹跳 + 随机鼓励语（写作/编程各有专属语录）
- **浮动详情面板**：点击状态栏弹出完整统计

### 🔧 智能管理
- **闲置自动暂停**：5 分钟无操作自动进入空闲状态
- **数据持久化**：插件数据自动保存，重启不丢失
- **一键重置**：随时可重置今日统计数据

## 📦 安装方法

### 方式一：从集市安装（推荐）
1. 打开思源笔记 → **设置** → **集市** → **已下载**
2. 搜索「**码字统计**」
3. 点击安装并启用

### 方式二：手动安装
1. 下载最新的 [Release](https://github.com/42970537/siyuan-plugin-wordcounter/releases)
2. 解压得到 `siyuan-plugin-wordcounter` 文件夹
3. 将文件夹放入思源工作空间的 `data/plugins/` 目录
4. 刷新思源笔记页面
5. 在 **设置 → 集市 → 已下载** 中启用插件

## 🚀 使用说明

1. **启用后**，右下角状态栏会出现码字统计指示器
2. **开始写作**，速率和字数实时更新
3. **点击状态栏**，查看浮动详情面板（含精灵 + 完整统计）
4. **拖动面板标题栏**，可自由移动面板位置
5. **点击精灵**，获得随机鼓励~

### 字数统计规则
- **码字模式**：中文字符计 1 字 + 英文单词计 1 字（适合写作）
- **编程模式**：所有非空白字符计 1 字符（适合代码）
- 统计基于编辑器内所有可见文本的**净增量**

### 速率颜色分级
| 等级 | 颜色 | 范围 |
|:---:|:---:|:---:|
| 闲置 | ⚪ 灰色 | 0 |
| 慢速 | 🟢 绿色 | < 10 字/分 |
| 中速 | 🔵 蓝色 | 10-30 字/分 |
| 快速 | 🟠 橙色 | 30-60 字/分 |
| 飞速 | 🔴 红色 | > 60 字/分 |

## 🔧 技术说明

- 通过 `input` 事件直接监听编辑器内容变化
- EMA 平滑算法计算主速率（增长快·衰减慢）
- 平均速率 = 今日总字数 ÷ 写作时间分钟数
- 数据存储使用思源插件系统的 `saveData/loadData` API
- 精灵角色使用纯 SVG 内联绘制，无外部依赖
- 面板拖拽通过 `mousedown/mousemove/mouseup` 实现

## 📸 预览

> 将鼠标悬停在状态栏指示器上即可看到实时码字速率，点击可展开完整面板。
